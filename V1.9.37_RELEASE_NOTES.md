# V1.9.37 — Dynamic Presentation Completion

## Goal
Make every selected job render six slides even when some source fields are unavailable,
while suppressing the missing field's label/value instead of displaying misleading
placeholders.

## Changes
- Field-aware presentation exposure for age, pay, fee, eligibility, selection and vacancies.
- Missing or contaminated fields are blanked from the Qwen presentation payload.
- Missing field labels/values are removed from the final slide plan.
- Application-date QA is line-aware and no longer mistakes walk-in/exam/training dates
  for application dates.
- Canonical application start/end remain deterministic.
- Slide 4 dynamically renders only available AGE / PAY / FEE cards.
- Slide 5 dynamically renders only available application-date timeline nodes.
- Missing application dates no longer produce a visual "See official notification" timeline.
- Existing factual reconciliation remains intact; source warnings remain auditable.
- Existing six-slide renderer and batch scripts retained.

## Validation
- Full test suite: 66 passed.
- Existing three-job Qwen plan smoke validation: all 3 slide gates PASS.
- Existing three-job render smoke validation: 6 PNGs per job (18 total).
