# V1.9.32 included helper scripts

- `scripts/test_three_jobs.sh`
  - Crawls `JOB_COUNT` jobs.
  - Processes each Job Detail DOCX independently.
  - Uses `--job-index 1` for each single-job DOCX.
  - Generates Qwen JSON and renders six slides per job.
  - Continues after an individual job failure.
  - Applies `chmod -R 777` to test output directories.

- `scripts/diagnose_batch_failure.py`
  - Reports source gate, slide gate, errors, warnings,
    presentation fallbacks and slide count for each Qwen plan.
