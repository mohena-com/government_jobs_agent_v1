# V1.9.23

Built directly on the attached latest workspace.

## Fixes

1. **Non-RVUNL official PDFs no longer classify as UNKNOWN.**
   The previous verifier only had detailed classification logic for RVUNL. Valid official PDFs from BOB, SAIL, courts, banks, universities, etc. were therefore discarded before reconciliation.

2. **Generic official-PDF verification added.**
   Conservative extraction covers advertisement number, dates, vacancy count, age, pay, eligibility, selection, fee and application instructions where safely identifiable.

3. **Invalid auxiliary links no longer poison a valid official PDF.**
   SarkariResult detail URLs are skipped from PDF verification. Non-PDF responses remain audit errors, but a valid official notification can still establish verification.

4. **Generic verification no longer erases good DOCX facts.**
   Empty generic extraction means "not safely extracted", not "fact is empty".

5. **Batch mode added.**
   `main.py --batch-mode` writes the diagnostic JSON but does not raise a process-level exception for a quality-gate failure. This lets the daily runner continue to the next job.

6. **Daily runner remains macOS-compatible.**
   No `mapfile`/Bash 4 dependency.

7. **Rendering is only counted as successful when at least six PNGs actually exist.**

## Deliberately unchanged

- Duplicate/history filtering remains OFF.
- Future-date selection remains owned by the SarkariResult crawler.
- RVUNL's strict official reconciliation/profile remains intact.
- Source and slide quality gates are not bypassed.
